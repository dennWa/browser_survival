# Runde 36 – Qualitätswechsel-Schwarzbild-Fix, FPS-Limit (laufend)
- **FPS-Limit:** `client/kern/spielSchleife.js` `MAX_FPS` 60 (`localStorage.bs_maxfps`, 0 = aus). Nur `zeichne()` wird gedrosselt, feste Takte laufen weiter. Grund: 144-Hz-Monitor → GPU-Volllast (~100 W).
- **⚠ Schwarz-/„Nebel“-Bug beim Qualitätswechsel (GEFUNDEN, war nie Nebel):** `renderer.#wendeProfilAn`/`#setzeStufe` schalten `mond.castShadow` an bzw. legen die Sonnen-Schattenkarte neu an. Nachts/Dämmerung ist `mond.shadow.autoUpdate=false` (`#tageslicht`) → die Karte wird nie gezeichnet → leere Karte = „alles im Schatten“ → schwarzes Bild (Figur, Bäume, Boden weg, nur Taschenlampenkegel). Fix: `mond.shadow.needsUpdate = true` nach Profilwechsel und nach Karten-`dispose`. Repro/Regression: `node werkzeuge/test/qualitaetswechsel.mjs` (Nachts niedrig→hoch/mittel; kaputt ≈12 KB, gut ≈36–40 KB). Merke: jede neue Schattenkarte (Licht mit `castShadow` neu/umgebaut) braucht einmal `needsUpdate`, wenn ihr `autoUpdate` zeitweise aus ist.

- **Basisbau Block-Größe pro Spieler (1×1 / 4×4 / 8×8):** Rechtsklick im Bau-Modus mit gewähltem Block-Teil (`BAUTEILE[x].block`: Boden/Wand/Dach) öffnet Popup (`C:ui/bauMenue.zeigeGroessen`, Knopf `▦ n×n` für Touch). Wahl → `AKTIONEN.BAU_BLOCK {wert 1|2|4|8}` (⚠ Whitelist in `S:spielServer.js` ~521/555 – neue Aktionsfelder dort eintragen, sonst werden sie verworfen) → `S:basisbauSystem.setzeBauBlock` → `spieler.bauBlock` (Standard weiter `konfiguration.basisbau.blockGroesse`=2; `blockFuerSpieler`). `SPIELER_DATEN.bauBlock` kommt aus dem Spieler.
